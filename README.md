# YouTube Shorts Killer

PC 版 YouTube からショート動画の表示を徹底的に取り除くシンプルな Chrome 拡張です。ショート専用ページへ移動した場合も、通常のトップページへ自動で戻します。

## 主な機能
- ホーム・検索・チャンネルなどに挿入される Shorts の棚やグリッドを除去
- ナビゲーションの「ショート」リンクを削除し、トップやミニガイドの導線も無効化
- Shorts への内部リンクを含む動画カードを丸ごと削除し、関連・おすすめ欄からも排除
- Shorts バッジ・オーバーレイや「Shorts」チップなどの周辺導線も検知して除去
- `https://www.youtube.com/shorts/...` へ移動した際にトップページへリダイレクト

## 使い方（開発者モードで読み込む）
1. このリポジトリを任意のフォルダーに展開します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダーを選択します。
4. 拡張が有効になれば完了です。YouTube を再読み込みすると Shorts が表示されなくなります。

> **ヒント:** 「マニフェストが必要」と表示される場合は、`manifest.json` が直下にあるフォルダーを指定できていない可能性があります。GitHub から ZIP をダウンロードした場合は必ず解凍し、`YoutubeShortsKiller-main/manifest.json` が見えている状態のフォルダーを選択してください。

## ファイル構成
- `manifest.json` — 拡張の設定
- `src/contentScript.js` — ショート動画要素を検知して除去するスクリプト

## 補足
- 公式の Shorts プレーヤー URL にアクセスした場合は、自動で YouTube トップページへ戻ります。
- YouTube の UI 変更によってショート動画が再び表示される場合は、セレクターの追加や更新が必要になることがあります。
